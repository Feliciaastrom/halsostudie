Python-version
* Python 3.14.7

Projekt/mappstruktur
* data - innehåller CSV-filen
* health_study_1.ipynb – Huvudfilen med hela analysen
* requirements.txt – Python-bibliotek som krävs för att köra projektet


Så kör du projektet

* Ladda ner projektet från GitHub.
* Öppna projektet i Visual Studio Code.
* Installera biblioteken med pip install -r requirements.txt.
* Öppna /health_study_1.ipynb och kör cellerna uppifrån och ned.
